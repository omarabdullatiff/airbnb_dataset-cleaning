# airbnb Data Cleaning  Project

This project demonstrates data cleaning techniques in Python using pandas and other tools. The notebook contains steps from loading raw data to exporting a cleaned dataset.

## 📁 Files Included

- `Notebook.ipynb`: The main Jupyter Notebook containing the full data cleaning workflow.
- `Airbnb_Open_Data.csv`: The original unprocessed dataset.
- `cleaned_Airbnb_Open_Data.csv`: The cleaned version of the dataset after processing.

## 🧹 Cleaning Steps Covered
- Delete redundant columns 
- Handling missing values
- Removing duplicates
- Standardizing text
- Converting data types
- Exporting clean data

- Python 3.7+
- pandas
- numpy
- jupyter
